# v0.20.5 admission identity hotfix

Fixes discovery admission failures where established artists were rediscovered as new because older records carried authority IDs in `external_ids` but not `artists.ulan_id`. Admission now resolves ULAN, Wikidata, and Wikipedia identifiers through `external_ids` before inserting an artist, and backfills `artists.ulan_id` when safe.

No schema or SQL migration is required. After deploy, rerun **Admit ready candidates**; previously failed established artists should report as already present rather than unique-constraint failures.
