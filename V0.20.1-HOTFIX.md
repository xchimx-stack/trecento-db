# v0.20.1 hotfix

Fixes the Discovery & admission resolver audit failing with:

`Unexpected token 'A', "A server e"... is not valid JSON`

Cause: `server/handlers/discover-trecento.js` referenced an undefined `zeriSearch` symbol at module load time, causing the Vercel function to crash before returning JSON.

No SQL or Supabase schema changes are required for this hotfix. Deploy normally, then return to `/discover.html` and rerun the resolver audit or illuminator discovery.
